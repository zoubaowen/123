# 小宝角色与登录页人工验收

## 验收环境

- 桌面宽度：1440 × 900
- 平板宽度：768 × 1024
- 手机宽度：390 × 844
- 浏览器分别测试正常动画与“减少动态效果”模式

## 品牌与启动页

- [ ] 浏览器标题、启动页、登录页、主导航均显示“AI小宝学院”
- [ ] 启动页小宝清晰、居中，无裁切或变形
- [ ] 启动提示会轮换，页面就绪后启动层平滑消失
- [ ] 不再出现旧产品名称或旧版团子形象

## 登录互动

- [ ] 默认状态下小宝有轻微呼吸和眨眼动作
- [ ] 聚焦账号框时，小宝看向输入区域
- [ ] 聚焦密码框时，小宝遮住眼睛
- [ ] 提交登录时，小宝进入书写/等待状态，按钮不可重复提交
- [ ] 登录成功时，小宝庆祝后进入主界面
- [ ] 登录失败时显示安慰状态，并允许用户再次输入
- [ ] 键盘 Tab 顺序、回车提交、错误提示均可正常使用

## 九套课程装扮

- [ ] 学院、编程、AI、绘画、音乐、科学、机器人、阅读、探索共九套装扮均可辨认
- [ ] 装扮只改变服饰和道具，小宝的脸型、星星天线与主体比例保持一致
- [ ] 首页课程区在桌面、平板、手机下无重叠或横向溢出
- [ ] 核心任务与聊天界面的小宝装扮和场景语义匹配

## 动效与可访问性

- [ ] 开启“减少动态效果”后，循环动画停止或明显减弱
- [ ] 页面缩放至 200% 时仍可完成登录
- [ ] 小宝装饰图不会干扰读屏，关键状态有文字反馈
- [ ] 深色背景下文字、输入框和主要按钮具有足够对比度

## 回归检查

- [ ] 创建任务、进入聊天、查看任务列表的原有流程不受影响
- [ ] 刷新页面后不会卡在启动层
- [ ] 登录请求失败、超时或网络断开时界面不会白屏
- [ ] 控制台无新增运行时错误
