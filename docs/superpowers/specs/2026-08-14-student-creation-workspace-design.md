# AI小宝学院学生创作工作台设计

## 阶段目标

以 `C:\Users\49781\Desktop\新建文件夹 (2)\学生创作工具界面.jpg` 为布局参考，重构学生进入产品后看到的创作主页。第一阶段完成工作台框架、创作入口和小宝引导，不在同一阶段接入全部课程、Skills 与 MCP 服务。

## 产品定位

学生创作工具是 AI小宝学院的核心学生端。它不是单一的代码编辑器，而是面向中小学生的综合 AI 创作与学习工作台，最终支持游戏、视频、音乐、图片、写作、作业辅导、解题和自主学习。

## 页面结构

### 左侧：学习与作品导航

- AI小宝学院品牌与学生欢迎语。
- “新建创作”作为主要入口。
- 作品广场、学生课程、成长记录三个产品入口；未完成模块明确显示“即将开放”。
- 会话搜索、置顶项目、最近创作和定时任务。
- 保留现有任务数据和导航能力，不伪造课程或成长数据。

### 中间：小宝创作台

- 空白状态显示小宝、欢迎语和适合学生理解的引导。
- 输入框上方提供图片、视频、音乐、游戏、写作、学习六类快捷创作入口。
- 点击快捷入口只填入对应的示例创作意图，不绕过现有任务创建流程。
- 输入框保留模型选择、附件、语音和提交能力。
- 创建任务后继续进入现有 AI 对话与任务工作区。

### 右侧：项目与素材

- 保留现有项目文件、预览和产物管理能力。
- 空白状态展示“项目素材会出现在这里”，并用图片、音乐、视频、代码、文档图标解释支持范围。
- 第一阶段不新增虚假的文件或素材数据。

## Skills 与 MCP 预留

### 学生能力分类

- 游戏创作
- 视频创作
- 音乐与音效
- 图片与海报
- 写作与阅读
- 数学与科学解题
- 学习复习与测验
- 课件与互动网页
- Arduino、micro:bit 与机器人

### 调用原则

- Skill 负责教学步骤、表达方式和任务流程。
- MCP 负责生成媒体、运行程序、读取资料或操作项目等真实工具能力。
- 后续由意图路由器选择 Skill，再按需申请对应 MCP；主页不让中小学生理解技术名词。
- 所有面向学生的 MCP 使用白名单、权限提示、内容安全和隐私保护。
- 作业与解题默认采用启发式步骤，不以直接代写、代答作为产品目标。

## 视觉方向

- 参考图的三栏信息结构，不复制其品牌和角色素材。
- 使用 AI小宝学院现有奶油白、薄荷绿、星光蓝与暖橙配色。
- 小宝是中心视觉锚点，保持星星天线、深色脸部和星光披风的统一识别。
- 控制装饰密度，确保工作台长时间使用不疲劳。
- 桌面端为主；较窄窗口下右侧素材区可折叠，左侧导航缩窄。

## 安全与无障碍

- 不展示真实密钥、内部路径或工具协议名称。
- 重要功能可用键盘操作，图标配有文字或可访问名称。
- 尊重“减少动态效果”设置。
- 错误提示使用学生可理解的语言，并给出下一步操作。

## 第一阶段验收标准

- 学生进入主页后能立即理解“告诉小宝想做什么”。
- 桌面端呈现左侧导航、中间创作台、右侧项目素材的三栏结构。
- 六类快捷入口均能正确生成或填入创作意图。
- 原有创建任务、会话历史、模型选择、附件和语音能力不丢失。
- 未上线的课程、成长和 Skills/MCP 能力不会被误认为已经可用。
- 生产构建、类型检查和代码检查通过。
