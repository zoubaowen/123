# 教师端课程管理设计

## 目标

将 `/teacher/courses` 从建设占位页升级为教师可实际使用的课程管理入口，打通“浏览课程—查看课程详情—准备课时—分配班级—开始上课”的核心备课闭环。

本阶段继续使用类型明确的演示数据和可替换仓库接口，不新增后端持久化接口。课件、作业、Skills 与 MCP 提供真实数据结构、当前配置和明确入口，但不伪装成已经完成的复杂内容编辑器。

## 用户与核心场景

主要用户是机构授课老师。核心场景为：

1. 老师进入课程中心，查看机构当前可用课程。
2. 老师按名称、学段、主题或状态筛选课程。
3. 老师进入课程详情，了解课程目标、预期成果、课时编排和班级分配。
4. 老师进入指定课时的备课页，查看教学步骤、资源和 AI 能力配置。
5. 老师将课程分配给自己负责的班级。
6. 老师从指定课时发起开课，复用现有开课配置和活动课堂流程。

## 方案选择

采用“课程库 + 课程详情 + 课时备课 + 班级分配 + 开课联动”的渐进式方案。

不采用完整课程内容生产编辑器，因为课件、作业、Skills 和 MCP 各自需要独立的编辑、校验、权限和持久化能力；本阶段同时展开会超出单个教学闭环的范围。也不采用只读课程浏览，因为它无法支持老师完成备课和分班。

## 范围

### 本阶段实现

- 课程中心数据摘要：课程数量、总课时、已分配班级数和待完善课程数。
- 课程卡片：课程封面、名称、学段、主题、状态、课时数、关联班级数和完善度。
- 搜索与筛选：按课程名称、学段、主题和课程状态即时筛选。
- 课程详情：课程目标、适合年龄、预期作品、能力标签、章节与课时列表、班级分配情况。
- 课时备课：教学目标、课堂步骤、教师提示、资源清单、作业说明、推荐 Skills、MCP 与 AI 能力。
- 班级分配：基于当前教师负责班级更新课程演示仓库中的分配关系，并在课程详情即时反馈。
- 开始上课：从指定课时复用 `StartClassDialog`、教师课堂状态仓库和 `/teacher/classroom/active`。
- 空结果、无效课程 ID、无效课时 ID 和已存在活动课堂等边界状态。
- 使用九宫格标准小宝生产资源提供备课提示和空状态反馈。

### 本阶段不实现

- 富文本教案编辑器、课件制作器和文件上传。
- 作业题型编辑器、评分规则编辑器和自动批改。
- Skills 或 MCP 的安装、授权、密钥配置与在线调试。
- 课程版本发布、审核、共享市场和跨机构复制。
- 新建、删除课程以及后端数据库持久化。
- 学生端课程学习页面和 `/admin` 技术运维功能。

## 信息架构

### `/teacher/courses`

页面从上到下包含：

1. 标题区：课程中心说明和返回教学首页入口。
2. 数据摘要：课程总数、总课时、已分配班级、待完善课程。
3. 搜索及学段、主题、状态筛选。
4. 响应式课程卡片网格。
5. 小宝备课提示；筛选无结果时改为可恢复空状态。

课程卡片主操作为“查看课程”，次级信息明确课程状态和完善程度。页面不展示无法持久化的新建或删除按钮。

### `/teacher/courses/:courseId`

页面由以下区域组成：

1. 面包屑、课程标题、学段和状态。
2. 课程概况：目标、适合年龄、预期作品、课时和能力标签。
3. 班级分配区：展示当前分配班级，并允许从教师负责班级中勾选分配。
4. 章节与课时编排：按章节显示课时顺序、时长、完善状态和准备入口。
5. 小宝备课建议。

班级分配仅更新教师演示数据上下文，界面明确使用“保存本次演示配置”的语义，不暗示云端已持久化。

### `/teacher/courses/:courseId/lessons/:lessonId`

页面由以下区域组成：

1. 课程和章节面包屑、课时标题、建议时长与完成度。
2. 教学目标和课堂步骤。
3. 教师提示及个人备课说明。
4. 课件、示范作品、作业和教学资源清单。
5. AI 能力、Skills 和 MCP 配置摘要。
6. “开始上课”主操作。

开始上课时，使用当前课时推荐配置作为 `StartClassDialog` 默认值；老师仍可在弹窗中调整积分上限和能力选择。若课程尚未分配班级，则禁用开课并引导返回课程详情分配班级。

## 视觉与交互

- 延续教师端现有浅色蓝白工作台、圆角卡片、轻边框和紧凑数据密度。
- 课程封面使用项目内真实视觉资源或已有品牌资产，不使用 emoji、自制 SVG、CSS 插画和占位框。
- 图标使用现有 Lucide 图标库，小宝使用 `@ai-xiaobao/chat-core` 中九宫格标准生产资源。
- 主操作使用蓝色填充按钮，次级操作使用描边或文字按钮。
- 1440×900 下课程卡片使用三列，1366×768 下至少两列，窄桌面允许单列且页面不横向溢出。
- 状态同时使用颜色、文字和图标表达，不能只依赖颜色。
- 搜索和筛选即时更新本地派生列表，不触发网络请求。

## 数据模型与组件边界

新增教师课程领域类型：

- `TeacherCourseStatus`：`ready | draft`。
- `TeacherCourseStage`：小学低年级、小学高年级、初中等稳定标识。
- `TeacherCourseSummary`：课程卡片和筛选需要的摘要信息。
- `TeacherCourseChapter`：章节标题、顺序与课时集合。
- `TeacherCourseLessonDetail`：目标、步骤、资源、作业和 AI 配置。
- `TeacherCourseDetail`：课程概况、章节、班级分配和完整课时信息。

课程数据继续由教师演示数据提供，但查询和更新逻辑放在独立课程仓库中，页面不直接实现筛选、查找或分配规则。

建议组件：

- `TeacherCoursesPage`：课程中心编排、搜索和筛选状态。
- `TeacherCourseCard`：单个课程摘要和详情入口。
- `TeacherCourseDetailPage`：详情编排、分配班级和章节列表。
- `TeacherCourseOutline`：章节与课时展示。
- `TeacherLessonPreparationPage`：课时备课编排和开课连接。
- `TeacherLessonResourceList`：课件、作业和资源清单。
- `TeacherLessonAiConfig`：能力、Skills 与 MCP 摘要。

共享课堂状态继续由 `TeacherWorkspaceProvider` 管理。课程页面不复制活动课堂状态，也不把课程数据写入学生创作平台状态。

## 数据流

1. 课程中心从教师课程仓库读取课程摘要。
2. 搜索和筛选通过纯函数返回派生列表，不修改源数据。
3. 点击课程卡片进入 `/teacher/courses/:courseId`，通过课程 ID 查询详情。
4. 班级分配调用演示仓库更新函数，更新教师上下文内的课程分配关系。
5. 点击课时进入 `/teacher/courses/:courseId/lessons/:lessonId`，同时校验课程和课时归属。
6. 开课入口根据所选课时和已分配班级生成 `StartClassInput` 默认配置。
7. 确认开课后调用现有 `startClass`，成功后进入 `/teacher/classroom/active`。

## 错误与边界处理

- 搜索无结果：展示“没有找到课程”，提供清除筛选按钮。
- 无效课程 ID：安全返回 `/teacher/courses`。
- 无效课时 ID 或课时不属于当前课程：安全返回对应课程详情。
- 课程未分配班级：不构造无效开课数据，提示先完成班级分配。
- 课程没有课时：展示明确的待完善状态，不出现空白区域。
- 已有课堂进行中：沿用 `startClass` 保护，不允许开启第二个课堂。
- 演示分配失败：保留原状态并显示可理解提示，不输出动态敏感信息。

## 测试与验收

- 纯函数测试：课程关键词、学段、主题、状态筛选；详情和课时查找；班级分配去重。
- 页面测试：摘要指标、课程卡片、筛选无结果、课程详情、章节课时、资源和 AI 配置。
- 路由测试：课程中心、课程详情和课时备课路由均注册；无效 ID 安全返回。
- 联动测试：已分配课程能以指定课时打开开课弹窗并进入现有课堂；未分配课程不可开课。
- 回归测试：教师首页、班级管理、开始上课、活动课堂和学生创作平台继续通过。
- 必须执行：`pnpm.cmd --filter @ai-xiaobao/web test`、`pnpm.cmd type-check`、`pnpm.cmd lint`、`pnpm.cmd --filter @ai-xiaobao/web build`。

## 完成标准

- 教师导航中的课程中心不再是占位页。
- 老师可以筛选课程并进入任一有效课程详情。
- 课程详情清楚展示课程目标、班级分配和章节课时编排。
- 老师可以从任一有效课时查看完整备课信息。
- 已分配班级的课时可以连接现有开课配置与活动课堂流程。
- 页面不暗示尚未接入的课程生产、上传或云端持久化能力已经可用。
- 学生创作平台和 `/admin` 技术后台不被混入教师课程模块。
