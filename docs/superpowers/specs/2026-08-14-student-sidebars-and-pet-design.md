# AI小宝学院学生工作区侧栏与宠物系统设计

## 目标

在不改动现有任务创建、Skills、MCP 与任务历史逻辑的前提下，让学生创作工具更接近参考图的桌面创作软件结构，并把“小宝宠物系统”放到课程区旁边。

本轮只完成学生工作区首页的侧栏体验和宠物入口，不建设完整课程详情页、宠物商城或后端成长数据。

## 方案选择

采用“轻量可交互外壳”方案：左侧保留真实任务历史并增加课程与小宝入口；右侧保留资源面板，同时提供真实可切换的文件、素材、课程三个视图。宠物数据先使用前端状态和明确的占位信息，后续再接机构后台及学生成长数据。

没有采用纯静态仿图，因为学生点击后没有反馈；也不在本轮直接建设完整课程和宠物后端，以免扩大范围并拖慢创作工具交付。

## 左侧区域

- 顶部继续显示 AI小宝学院品牌和“新建创作”。
- “我的课程”从禁用项改为可选择入口，展示课程区即将接入的说明，不虚构课程进度。
- 在“我的课程”旁增加“小宝伙伴”入口，显示小宝当前心情、等级占位和今日陪伴状态。
- 最近创作继续使用真实任务列表；搜索框只筛选当前可见任务，不增加新接口。
- 保留作品广场和成长中心入口，其中成长中心仍明确标记为即将开放。

## 小宝宠物卡

- 使用项目现有 `XiaoBao` 角色组件和 academy 装扮，不生成替代角色。
- 默认状态为“开心、挥手、正在陪伴创作”。
- 提供“和小宝打招呼”按钮，点击后在几种友好文案与动作状态间切换。
- 等级、星光值、连续陪伴天数均标记为演示占位，不写入数据库，也不伪装成真实成长数据。
- 未来由学生账号、课程完成记录、作品发布与节日装扮共同驱动。

## 右侧资源区域

- 桌面端保持固定右栏；较窄屏幕使用可打开、可关闭的抽屉，而不是无响应的悬浮按钮。
- 三个页签：项目文件、创作素材、课程资料。
- 空状态根据页签切换，说明内容何时会出现，并提供可用的关闭或切换操作。
- 顶部加入当前创作空间状态，不展示虚假文件。

## 交互与数据流

1. 左侧入口只改变学生工作区的局部视图状态，不影响路由与任务提交。
2. 六类创作能力仍然把安全提示词写入现有创作输入框。
3. 小宝互动状态只保存在组件生命周期内，刷新后恢复默认。
4. 右侧页签与移动抽屉状态由资源面板内部管理。
5. 原有 TaskForm、Skills、MCP、连接器和任务创建请求保持不变。

## 响应式与无障碍

- 1280px 以上同时显示左侧栏、中央创作区和右侧栏。
- 中等屏幕隐藏右侧栏，使用抽屉按钮；小屏幕保持中央创作流程优先。
- 所有入口使用真实按钮或链接，包含可读标签、选中状态、键盘焦点样式。
- 动效遵循减少动态效果设置，小宝互动不使用强闪烁。

## 测试与验收

- 先写失败测试，覆盖课程入口、小宝入口、宠物互动按钮、第三个资源页签和移动抽屉开关。
- 保持现有学生工作区测试全部通过。
- 执行 TypeScript 类型检查、ESLint 和 Web 构建。
- 使用参考图相同桌面比例完成浏览器视觉检查；若登录环境仍阻止工作区截图，明确记录视觉验证受阻，不把构建成功当作视觉通过。

## 后续边界

后续独立迭代再建设：课程目录与学习路径、宠物成长持久化、节日装扮轮换、机构后台课程投放、教师查看学生成长记录。
